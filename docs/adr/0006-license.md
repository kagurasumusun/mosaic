# 0006: ライセンスと貢献規約

状態: **未決定（オーナー・必要に応じ法務判断待ち）**。根拠: 構成設計書 §21, §23。

ライセンス付与や DCO / CLA の選択はエージェントが代行しない。
初期段階では Unicorn 導入を保留していましたが、ユーザーの明示的な導入指示に基づき、
ADR 0007 の範囲で開発・CI 検証用の依存を追加しました。リンクする配布物の条件については
引き続き確認が必要です。導入許可を、ライセンス付与や法的確認の完了とみなしません。
動的リンクやプロセス分離だけで法的問題が解決するとみなさない。

オーナーに確認すること:

1. GPL 互換で公開する方針（設計書の案 A）か、内部開発後に公開する方針（案 C）か。
2. ソースと配布物の SPDX ライセンス、貢献者合意、将来の再ライセンスの要否。
3. 公開・配布の時期とレビュー責任者。

暫定措置:

- 全 Cargo パッケージを `publish = false` にし、未承認の SPDX を記載しない。
- LICENSE は捏造しない。これは「自由に再利用できる」という意味ではない。
- 外部 crate は xtask の TOML / JSON 処理と、専用 engine 境界の Unicorn に限定する。
  Unicorn crate の申告ライセンスは GPL-2.0。version・features・出自を明記する。
- CLI の Unicorn リンクは opt-in。CI のビルド以外に release / バイナリ配布は追加しない。
  publish = false や feature 分離がライセンス条件を免除するとはみなさない。
- 他プロジェクトのモデルを読み写さない。将来のモデルに spec / derived_from を記録する。

決定後の作業: LICENSE、各 Cargo.toml の license 継承、CONTRIBUTING、
cargo-deny のライセンス許可リストと CI、必要な出自記録を同じ変更で導入する。
この ADR が未決定のままでは P0 の初日判断は完了せず、配布は開始しない。
