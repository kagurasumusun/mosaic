# 0003: u64 ピコ秒と決定論

状態: 暫定採用。根拠: 構成設計書 §12.4, §13.2。

VTime は u64 ピコ秒。約 213 日で上限に達するため、加算は checked operation とし、
暗黙の wrap や飽和を禁止する。長期間のシナリオで不足する場合は、安定化前に再検討する。
ホストの実時間をモデルから直接参照しない。

実装予定: 単一スレッド、固定順のコア実行、イベントは (time, insertion sequence) 順。
過去への予約、時刻・sequence・EventId のオーバーフローをエラーにする。
量子は P1 の実測後に決める。命令数を物理的なサイクル精度として扱わない。

実装済み: VTime と checked_add の境界テスト。
未実装: スケジューラ、イベントキュー、clock tree、実時間同期。
