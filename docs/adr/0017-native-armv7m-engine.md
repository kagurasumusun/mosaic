# 0017: ARMv7-M は自前エンジンで実行する

状態: 初期実装を採用。ARMv7-M 全体を実装したとはみなさない。

根拠: 設計書 §12.1、§12.2、ADR 0001、ADR 0009、ADR 0012。

## 背景

Unicorn は T32 の実行経路として既にある（ADR 0012）。設計書 §12.1 は、Unicorn の
ISA 一覧に無い命令セットを足す道を「自前エンジンを ISA ごとに足す」と定めており、
`engine/native/` をその置き場にしている。STM32F103 スライスは宣言済みの機械を
`MachineBus` で実行する。その実行が Unicorn のラッパやファームウェア手順の
スタブだと、VM のコアがまだ無い。

## 決定

- `mosaic-engine-native-armv7m` が `CpuEngine` を実装する。Unicorn には依存しない。
  1 インスタンスは 1 コア。SoC の番地を知らない。MMIO は命令幅の 1 トランザクション
  として `EngineBus` へ出す。バイトに割って 4 回書かない。
- Thumb-1 と 32 ビット BL を実行する。未知の Thumb-2 は推測せず、PC を進めずに
  例外として止める。IT 状態は IT 命令自身では進めず、ブロック内の後続命令でのみ進める。
- 例外入口はアーキテクチャの 8 ワードフレームとベクタ語の読み出しで行う。SCS の
  番地をエンジンに埋め込まない。NVIC の優先度付けは `ip:arm/scs` に残す。
  `set_line` はラインの記録だけであり、それだけでは例外に入らない。
- 能力は `EngineCaps::PRECISE` で宣言する。契約の構造体は `non_exhaustive` のまま
  なので、クレート外からフィールドを組み立てない。
- 量子はエンジンの性質ではない。RCC のゲートは ADR 0001 の遅延イベントであり、
  ゲストが次の命令で USART を書く前に届ける必要がある。STM32F103 の native
  ハーネスは 1 命令ごとにドライバへ返す。量子 32 ではゲートが遅れ、CR1 の書込みが
  落ちてコンソールが空になる。
- ファームウェア画像は golden を満たすように直した実コードである。上位ニブルから
  印字し、A–F は `0x37` を加算する。CRL / BRR / ICSR のリテラルは、実際に LDR が
  指す語に置く。

## 受け入れ基準

- `NativeCortexM3` が Unicorn をリンクせず、宣言済み STM32F103 機械を
  `MachineBus` と `MachineDriver` で実行する。
- コンソールが `GOLDEN_OUTPUT` と一致し、PA5 のエッジが `[false, true]` になる。
- MMIO ワードはバス上で 1 回の幅 4 アクセスである。
- 未知のワイド命令はリタイアせず、実行専用領域へのストアは権限例外になる。

## まだ主張しないこと

- ARMv7-M の全命令、SysTick の再実装、命令タイミング、排他モニタ。
- Unicorn 経路の削除。native は置換候補であり、既存の Unicorn バインドは残す。
